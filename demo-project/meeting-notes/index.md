This nested page exists only because it deserves its own URL. That is the main rule for the starter.

## Decisions

- Stay close to stock 11ty.
- Use `index.md` as the normal page entry for folders.
- Keep navigation explicit by linking child pages from the parent page.
- Use `.gitignore` to keep working notes and non-site files out of the build.

## Follow-up

- Add another child folder only when the content becomes hard to scan on one page.
- Keep the parent project page updated with links to new child pages.

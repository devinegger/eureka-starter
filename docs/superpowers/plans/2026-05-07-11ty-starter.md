> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a minimal stock Eleventy starter in this workspace, replace the temporary example folder with cleaner demo content, and keep the setup aligned with the written spec.

**Architecture:** Use Eleventy with zero custom config so the starter stays close to stock behavior. Build the site from Markdown pages and a shared Liquid layout in `_includes`, with root-level project docs kept out of site content via `.gitignore`.

**Tech Stack:** Node.js, `@11ty/eleventy`, Markdown, Liquid, CSS
